⚽ FIFA 20 Player Performance Analysis | Power BI & Excel Project
📌 Project Overview

This project is an end-to-end data analytics case study built using FIFA 20 player data, a game I actively play and deeply understand. The objective was to transform raw, game-level player data into meaningful performance insights that can support decision-making such as player comparison, team building, and performance evaluation.

The project demonstrates the complete analytics lifecycle — data collection, validation, cleaning, modeling, analysis, and visualization — using industry-relevant tools.

🎯 Business Objective

Analyze player performance metrics across attacking, defensive, and overall attributes

Identify top-performing players based on position-specific KPIs

Enable data-driven player comparison through interactive dashboards

Convert raw game data into actionable insights

🧹 Data Cleaning & Preparation

Removed duplicate and invalid records

Standardized numeric and categorical columns

Handled missing values using logical imputation techniques

Created calculated fields and KPIs for performance analysis

Optimized data model using star schema principles

Tools used:

Microsoft Excel (data validation, profiling)

Power Query (data transformation)

Power BI Desktop (data visualization)
